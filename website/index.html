Wi-Fi, without the guesswork

Portway reads your interface, ARP neighbors, and the /24 you actually sit on. It will not walk a /8. Router admin pages, printers, NAS boxes, and that forgotten Flask process on a laptop all show up as doors you can open.

Tailscale, by name

If the Tailscale CLI is on PATH, Portway reads tailscale status --json and scans peers — online, offline, exit nodes included. MagicDNS hostnames stay attached so you open nas, not a CGNAT riddle.

Knows developer ports

Flask 5000, Vite 5173, Django 8000, Jupyter 8888, Plex, Jellyfin, Redis, Postgres, and the rest of the usual suspects.

All 65535, on purpose

Quick and Developer profiles stay fast. Deep mode walks every TCP port on a single host you choose.

Open, or copy

Web services get an Open button. SSH and databases get a copyable address. HTTP titles and Server headers are fingerprinted.

Stays on your side

No account. No telemetry. No remote targets. The scanner refuses public ranges and caps discovery at a /24.

How a sweep works

  1. Chart the piers

    Interfaces are classified as this machine, Wi-Fi / Ethernet, or Tailscale. Virtual bridges such as Docker are skipped.

  2. Connect, do not exploit

    A TCP connect scan with a short timeout. Open ports are optionally probed with a tiny HTTP GET to read the title.

  3. Open the ones that matter

    Click Open and the default browser takes the URL. Everything else copies as host:port.

Install and launch

Python 3.10 or newer. The desktop window is HeroUI in pywebview, backed by Flask. The TUI and CLI share the same scanner.

git clone https://github.com/portway-app/portway
cd portway
python -m venv .venv
source .venv/bin/activate
pip install -e .
portway                 # HeroUI desktop
portway serve           # Flask on :5050
portway tui             # terminal listing
portway list            # colored IPs

Save a Jupyter token: portway list --token 127.0.0.1:8888=YOUR_TOKEN

Requirements

  • Linux, macOS, or Windows
  • Tailscale CLI optional
  • Permission to reach local hosts

What Portway will not do

  • It will not scan the public internet or a range you are not attached to.
  • It will not walk more than a /24 during host discovery.
  • It will not run an all-port sweep against a whole subnet.
  • It will not send results anywhere. The process is local.
